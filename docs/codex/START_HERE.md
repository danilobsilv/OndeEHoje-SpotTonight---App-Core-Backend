# Start Here — Codex

The repository architecture has already been designed.

Codex should implement one milestone at a time and must not redesign the product unless explicitly asked.

## First command/prompt

After copying this package into the repository, use a prompt similar to:

```text
Read AGENTS.md and the documentation it references.
Then read docs/codex/M0_PROJECT_FOUNDATION.md.
Inspect the repository and implement M0 only.

Before making changes, summarize:
- the architecture you inferred,
- the constraints you must preserve,
- the files/components you expect to create or change.

After implementation:
- run the required tests,
- report all changed files,
- report test results,
- report any assumptions or divergence from the documentation,
- stop and do not start M1.
```

After reviewing M0, repeat with the next milestone document.
